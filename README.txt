L'ARTISAN POUR HOMME — SITE DEMO
===================================

Maquette multi-pages réalisée pour une présentation commerciale.

Pages:
- index.html
- pages/services.html
- pages/salon.html
- pages/galerie.html
- pages/contact.html

IMPORTANT:
- Les images sont des images d'illustration Pexels chargées depuis leurs URLs.
- Les tarifs sont volontairement indiqués "à confirmer".
- Les horaires/adresse/téléphone/Instagram ont été repris des informations publiques trouvées pour le salon, mais doivent être validés avant publication.
- Le bouton Planity pointe volontairement vers la page générale dans cette démo : remplacer par le lien exact de réservation du salon avant livraison.
- Remplacer les photos d'illustration par les photos réelles du salon dès accord du client.
